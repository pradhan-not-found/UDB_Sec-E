<summary><strong>Assignment 1: Image Metadata-Based Classification and Segregation</strong></summary>

<br/>

**Objective:**  
Develop a Python-based system to analyze and segregate images based on available EXIF metadata and location information.

**System Requirements:**
- **Extract Metadata:** Retrieve device manufacturer, model, GPS coordinates, and other available EXIF data from each image.
- **Device Segregation:** Group images by phone model (e.g., iPhone, Samsung Galaxy, Xiaomi, OnePlus, Vivo).
- **Location Segregation:** Use GPS data to determine whether an image was captured inside or outside the **Adamas University campus**.
- **Campus Areas:** For campus images, further categorize them into specific areas or locations where possible.
- **File Organization:** Automatically create appropriate folders and move/copy images into their respective categories.
- **Missing Data:** Place images lacking metadata or location information into an `Unknown/Unclassified` folder.
- **Reporting:** Generate a CSV report containing the extracted metadata and classification results.
- **Submission:** Maintain the project (source code, reports, organized output) in a public GitHub repository.

**Expected Workflow:**  
`Google Drive` &rarr; `Download ZIP` &rarr; `Extract Images` &rarr; `Extract Metadata` &rarr; `Device Classification` &rarr; `Location Classification` &rarr; `Campus Area Classification` &rarr; `Folder Segregation` &rarr; `Generate Report` &rarr; `GitHub Submission`
